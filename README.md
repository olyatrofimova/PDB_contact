# PDB_contact
Структуры, которые анализируем:
### 1FYT
Комплекс из трёх частей: рецептор Т-клетки (TCR), молекула MHC и пептид вируса гриппа. Это «система распознавания» иммунной клетки. 

### 1AKE
Фермент аденилаткиназа из кишечной палочки, связанный с молекулой-ингибитором, который останавливает его работу.

### 1XI4
Решётка (клетка) из белка клатрина, которая образует «сетку» вокруг клеточных пузырьков.

### 1E4K
Комплекс фрагмента антитела (IgG1) и рецептора к нему на поверхности иммунных клеток.

### 1Y64
Комплекс белка Bni1p (формина) с белком актином. Белок-организатор (формина) помогает собирать длинные нити актина (каркас клетки). Ещё один иммунный комплекс, интересен для сравнения с 1FYT.
