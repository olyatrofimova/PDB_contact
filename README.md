# PDB_contact
Анализ межцепочечных контактов в белковых структурах из RCSB PDB.

### Что делает
1. Загружает mmCIF-структуры из локальной папки /data;
2. Находит все пары атомов из разных цепей в радиусе < 5 Å (без H);
3. Строит бинарную матрицу контактов остаток–остаток;
4. Визуализирует карты контактов с номерами остатков и счётчиком пар.

### Структуры, которые анализируем:
**1FYT** - комплекс из трёх частей: рецептор Т-клетки (TCR), молекула MHC и пептид вируса гриппа. Это «система распознавания» иммунной клетки. 

**1AKE** - фермент аденилаткиназа из кишечной палочки, связанный с молекулой-ингибитором, который останавливает его работу.

**1XI4** - решётка (клетка) из белка клатрина, которая образует «сетку» вокруг клеточных пузырьков.

**1E4K** - комплекс фрагмента антитела (IgG1) и рецептора к нему на поверхности иммунных клеток.

**1Y64** - комплекс белка Bni1p (формина) с белком актином. Белок-организатор (формина) помогает собирать длинные нити актина (каркас клетки). Ещё один иммунный комплекс, интересен для сравнения с 1FYT.
